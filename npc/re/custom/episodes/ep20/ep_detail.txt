Notes:
- By default the folder should be in npc/re/custom/episodes/ which allow to load all the files by adding the path npc/re/custom/episodes/ep20/scripts_main.conf in npc/re/scripts_main.conf
  (+ the path pc/re/custom/episodes/ep20/barters.yml should be added to npc/barters.yml)
- Like in the previous episode, the reputation has 3 levels.
-- level 0 : npc not accessible
-- level 1 : unlock the basic shop (glacier equipment), enchants etc..
-- level 2 : unlock the costumes and glacier refine box shops
-- level 3 : additional reward from daily quests (+1 Ep20_Cat_Whiskers)
- 13 daily quests give Ep20_Cat_Whiskers (the 'money' of this episode) for a total of 13 * 3 = 39 items per day. When the reputation is level 3 : 13 * 4 = 52 items.
- 11 daily quests give +5 reputation points per complexion. Immortal instance give +20 points.
